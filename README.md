# Rest Time

默认中文的在线专注工作台，账户和数据保存在用户授权的文件夹或浏览器，无需 Terminal。

- 登录页可选择本地文件夹，或直接体验隔离的合成数据演示。
- 圆形启动按钮已修复；桌面、平板、手机使用响应式布局。
- “结束计时”立即停止计时，再询问补充信息并生成总结。
- AI 连接通过私人登录窗口使用 GPT-5.6 Luna 测试模型；保持连接窗口打开。密钥只保存在服务器。
- 演示回放原代码格式的合成摄像头/手环窗口与融合规则；未连接 AI 时明确标为演示脚本。
- 忘记密码和 JD 登录仍为占位功能；实时摄像头推理及训练权重仍需补齐。
